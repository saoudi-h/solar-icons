# AGENT: apps/docs-start/src/components/icons-page

Scope: `/icons` explorer UI, state, virtualized grid, and detail panel.

- **Previews & imports:** Use `useIconPreview` / `useIconComponent` in `sections/icons/icon-registry.tsx`. `generate:icon-catalog` embeds the initial default-style viewport and writes immutable JSON preview sets under `public/data/icon-previews/` (one slice per style/category). Keep the SVG wrapper on the package's `IconBase` so provider settings and isolated previews match package rendering. Do not restore whole-style or per-icon module imports for the grid.
- **Hydration & URL state:** Explorer URL hooks apply query parameters after hydration because static `/icons` HTML is identical across query strings. Capture shared-link scroll targets after that step, not on first render. Controls stay disabled/inert until hydration finishes; initial SVGs remain visible during this interval.
- **Catalogue & search:** Category/count state starts from the bundled full catalogue so the sidebar exists in server HTML. The category row and grid share initial height before viewport measurement. `src/generated/icon-catalog.json` holds shared category tags plus per-icon exceptions; preserve search tags/ranking when compacting (`utils.test.ts` compares both against tracked descriptions). Reuse search indexes across queries.
- **Exports:** SVG/PNG exports fetch `public/data/icon-svgs/<name>.<hash>.json` (6 styles, generated from core SVGs) from the same deployment; keep `/data/icons.json` separate from the compact client payload.
- **Grid:** Keep `react-virtualized`, measure container width, keep category/deep-link scrolling and search reset covered by Playwright, and render detail content directly. Compare scroll performance before changing virtualization. Cell sizes follow `getCellSize` in `context.tsx`; names are optional (`?names=on`, otherwise hover/focus, shown by one shared `Tooltip` in `IconNameTooltip.tsx`; never mount a Radix tooltip per cell, it slows scrolling). Call `recomputeRowHeights` / `recomputeGridSize` on cell size changes. Selection uses cell background and ring, never icon recolouring.
- **Layout & surfaces:** One toolbar row (search first; appearance controls collapse into a popover `< xl` and filter drawer `< md`), category sidebar `>= md`, grid, and `IconDetail` (`placement="side"` column `>= lg`, sticky sheet below reporting height so the last row stays visible — never overlay desktop grid). Surfaces come from `surface.ts` (`PANEL_SURFACE`, `CONTROL_SURFACE`): short shadow, no inner borders. Detail stage and variants follow provider settings; only the toolbar style picker is `isolated`.
- **Detail interactions:** Package snippet tabs are logo-only `role="tab"` buttons with tooltips/accessible names persisted in `localStorage`. Escape is handled on `window` capture, yielding to text fields and open dialogs/menus/listboxes; focus returns to the icon cell after exit animation across a few frames as the grid re-lays out.
