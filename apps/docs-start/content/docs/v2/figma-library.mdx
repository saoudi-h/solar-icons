Solar Icons is available as a free Figma Community file, maintained and extended by Hakim Saoudi.

[Open the Figma library](https://www.figma.com/community/file/1700288903247372375/solar-icons-dev-icon-library)

## Start with your own copy

Open the Community page and choose **Open in Figma** to create your copy. The exact button label may vary with Figma's interface. Edit that copy to suit your project.

Community copies do not receive updates automatically. Return to the Community page when you want the latest published version.

## Find and edit an icon

Categories are arranged horizontally on one page. Each category has its own section, with one row per icon and all six styles beside each other: Linear, Broken, Line Duotone, Outline, Bold and Bold Duotone.

The icons are main components. Use instances in your designs to keep them connected to the components in your copy. Category names, icon names and style headings are locked so they do not interfere with editing.

## Customize with variables

Open Figma's **Variables** panel and select **Solar Workspace**:

- **icon/color** controls icon colour.
- **icon/stroke-width** controls the standard live-stroke width; its default is 1.5 px.
- **icon/duotone-opacity** controls the attenuated parts of duotone icons; its default is 50%.

These are file-wide values: changing one updates every object bound to it in your copy. Override an individual icon when you only want a local change.

Linear, Broken and Line Duotone retain editable strokes. Outline, Bold and Bold Duotone use filled geometry, so changing stroke width does not apply to them. Some small details retain their original width and are not bound to the standard stroke-width variable.

## Prefer to insert icons into an existing file?

The [Figma plugin](/docs/v2/figma-plugin) lets you search and insert icons without copying the full library.

[Get the Figma plugin](https://www.figma.com/community/plugin/1664759238792120976)

## Request or contribute an icon

Missing an icon for a real use case? [Request an icon](/docs/v2/community/request-an-icon). You do not need to submit a drawing.

To contribute artwork, read the [contribution guide](/docs/v2/community/contributing) and agree on the scope in an issue before drawing or opening a pull request.
