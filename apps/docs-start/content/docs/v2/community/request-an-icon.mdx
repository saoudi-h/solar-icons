Missing an icon? Tell us what you need. You do not have to draw it, write code or submit a pull request.

[Request an icon on GitHub](https://github.com/saoudi-h/solar-icons/issues/new?template=icon-request.yml)

## Before submitting

Search the [catalogue](/icons) using the concept and related terms, then check [existing requests](https://github.com/saoudi-h/solar-icons/issues). If a request already covers your need, add your use case to that discussion.

## What to include

The same GitHub form supports both requests and design proposals. Choose whether you only need an icon or would like to help draw it. The form asks for:

- A name or short description of the concept.
- The screen, action or real situation where you would use it.
- The closest existing icons and why they do not fit.
- Optional screenshots or references, with their sources.
- Whether you would like to help with the design. Requesting an icon alone is welcome.

Keep related concepts in one discussion. If you want to propose a group of icons, explain how they belong together so the scope can be agreed before work starts.

## What happens next?

We review the need, check for duplicates and discuss naming and scope. An accepted request does not promise a delivery date.

If you already have an open request, continue in that issue rather than opening a separate proposal.

If you want to contribute the drawing, wait for agreement first. Review starts with an editable Linear version; the other five styles follow after its approval. See [Contributing](/docs/v2/community/contributing).
