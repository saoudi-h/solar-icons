# Changelog

## 2.0.1

- The package description and README no longer describe the package as an unreleased preview, and the installation instructions use NuGet.org.

## 2.0.0

- Native Blazor components for the full catalogue, generated static and dynamic styles, compatibility aliases, accessibility, CSS theming, and duotone controls.
- Catalogue drift checks, a Blazor playground, rendering verification, and independent NuGet consumption and trimming probes.
- .NET 8 library target with .NET 8 and .NET 10 rendering and trimmed WebAssembly validation.
- TypeScript generation, a separate playground under `apps/blazor-app`, compilation measurements, and static/dynamic comparisons for 1, 50, and all icons.
- Attribute-escaping checks, qualified-name coexistence with another icon library, and browser verification of published consumers.

The version follows the 2.x line of the other packages. The project maintainer owns maintenance and publishing, which run from this repository's CI.
