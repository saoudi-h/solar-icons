# AGENT: packages/figma-plugin

- **Type & role:** Private workspace package for the public Figma Community plugin to browse and insert the Solar Icons SVG distribution.
- **Asset architecture:** `scripts/build.mjs` embeds all 6 styles from `packages/static/dist/icons.json` as DEFLATE-compressed base64 (decompressed once in UI via `fflate`), plus metadata, package marks, and provenance (static version, logical/SVG counts, deterministic hash). Keep total bundle under 13.5 MiB (`pnpm check:figma-catalog` verifies). Zero external network access (`allowedDomains: ["none"]`); purge legacy download caches; keep settings local.
- **Source & tooling:** Sandbox in `src/main`, message contracts in `src/shared`, React UI in `src/ui` (never edit `dist/code.js` or `dist/ui.html`). Vite bundles/inlines UI; esbuild bundles sandbox; Base UI supplies Tabs/Select. Keep plain CSS (no Tailwind without demonstrated benefit). Avoid optional chaining (`?.`) and nullish coalescing (`??`) in `src/main`. Communicate via `postMessage`.
- **UI & brand:** Compact flat utility UI aligned with docs and Figma: semantic Figma theme tokens, continuous grids, fine dividers, `#6b5be6` brand accent, Host Grotesk body, Aleo titles, embedded Solar UI icons, `devicon`/`vscode-icons` package marks (grayscale until hover). No duplicate in-plugin title header; default 300px width, resizable from all edges/corners; Icons, Settings, Info tabs. Explicit light/dark previews persisted alongside system theme.
- **Grid & search:** Parse full library in UI only (never in sandbox); mount only visible rows + buffer; column count follows width; never cap results or fetch per preview. Reuse one Fuse index (`name`, `tags`, `category`, `categoryTags`, threshold `0.2`, `ignoreLocation: true`) with AND semantics for multi-term queries.
- **Controls & insertion:** Support immediate insertion and multi-selection; persist settings via `figma.clientStorage` on commit (not every drag frame). Linear, Broken, and Line Duotone support stroke-width (do not call them "Linear icons"); filled styles receive no stroke override. Size/stroke support scrubbing, keyboard increments, double-click reset, and live preview.
- **Publication boundary:** CI verifies the bundle; Figma Community publication is manual per `docs/FIGMA-PLUGIN-PUBLISHING.md` and `docs/FIGMA-CATALOG-SYNC.md`.
